# Rapido Ride Analytics Dashboard | Power BI

## Project Overview
An interactive Power BI dashboard that analyzes Rapido ride data to uncover insights into booking trends, cancellations, customer satisfaction, and ride performance.

## Dashboard Pages
- **Ride Intelligence:** Booking status, booking trends, and booking value.
- **Cancellation Insights:** Cancellation patterns, rates, and incomplete rides.
- **Customer & Ride Performance:** Customer ratings, ride distance, ride duration, payment methods, and weekday vs. weekend bookings.

## Tools & Technologies
- Microsoft Power BI
- DAX
- Microsoft Excel
- Data Visualization

## Key Insights
- Analyzed 30,000 ride bookings.
- Evaluated booking completion and cancellation rates.
- Compared ride performance across vehicle types.
- Examined booking value by payment method.
- Compared weekday and weekend booking patterns.

## Purpose
To transform ride-booking data into meaningful business insights through interactive dashboards and data visualization.

*Note: This is an independent analytics project using a Rapido-themed dataset, not an official Rapido business report.*
